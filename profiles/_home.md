# lewis.md

Hi, I’m [Benedict Lewis](https://ben.lewis.md). I built this as a small home on the web for me and my family.

If you’re a Lewis and would like to add or update a free page here, [email me](mailto:ben@bl.je) your Markdown (`.md`) file or [open a pull request](https://github.com/0x62/lewis-md/pulls) to add or edit `profiles/yourname.md`. Subdomains are first names only, and the name must not already be taken.

If you’d like an `@lewis.md` email address, I may be able to arrange one at cost. Just ask.

There’s no control panel. It’s a small personal project, so there are no guarantees about uptime, support or how long it’ll be around.

The domain isn’t for sale.
